## تشغيل المشروع محليًا

1. فك ضغط الملف `galal-academy.zip` في أي مكان على جهازك.
2. افتح الفولدر `galal-academy` في VS Code (`File → Open Folder`).
3. ثبّت إضافة **Live Server** من Extensions (لو مش مثبتة).
4. دوس Right Click على `index.html` → **Open with Live Server**.
5. الموقع هيفتح تلقائيًا على حاجة زي `http://127.0.0.1:5500`.

في المرحلة دي، الموقع هيشتغل بصريًا بالكامل، بس تسجيل الدخول والاشتراكات لسه محتاجين تفعّل Firebase (الخطوة الجاية).

## إعداد Firebase من الصفر

> ملحوظة: مشروع Firebase بتاع Galal Academy (`galal-academy-da457`) **موجود بالفعل ومربوط** في `firebase/firebase-config.js` و`.firebaserc`. الخطوات دي للمرجعية لو عملت مشروع جديد من الصفر مستقبلًا، أو لو حد تاني هيكمل شغل على المشروع.

### 1. إنشاء المشروع
1. روح [console.firebase.google.com](https://console.firebase.google.com).
2. **Add project** → اكتب اسم المشروع → كمّل الخطوات.

### 2. تفعيل Authentication
1. من القائمة الجانبية: **Build → Authentication**.
2. **Get started** → تبويب **Sign-in method**.
3. فعّل **Email/Password**.

### 3. إنشاء Firestore Database
1. من القائمة الجانبية: **Build → Firestore Database**.
2. **Create database** → اختار **Production mode** → اختار المنطقة الأقرب (زي `eur3` أو `me-central1`).

### 4. تفعيل الـ Security Rules
1. من Firestore Database → تبويب **Rules**.
2. امسح اللي موجود، والصق محتوى `firebase/firestore.rules` كامل.
3. دوس **Publish**.

### 5. الحصول على بيانات الاتصال (Config)
1. من **Project Settings** (⚙️ بجانب Project Overview) → **General**.
2. انزل لـ **Your apps** → لو معملتش Web App قبل كده، دوس على أيقونة `</>`.
3. انسخ الـ `firebaseConfig` object.
4. الصقه في `firebase/firebase-config.js` بدل القيم الموجودة.

### 6. تحويل أول حساب لـ Admin
1. اعمل حساب عادي من `register.html` في الموقع.
2. روح Firestore Database → Collection `users` → افتح مستند حسابك.
3. غيّر قيمة الحقل `role` من `"student"` لـ `"admin"`.
4. سجّل خروج ودخول تاني، وادخل على `admin/admin-dashboard.html`.

## رفع المشروع على GitHub

1. لو معندكش حساب GitHub، اعمل واحد من [github.com](https://github.com).
2. اعمل Repository جديد (من غير ما تختار "Initialize with README" عشان عندك واحد بالفعل).
3. من جوه مجلد `galal-academy` في الـ Terminal (داخل VS Code: `` Ctrl+` ``):

```bash
git init
git add .
git commit -m "أول نسخة من منصة جلال أكاديمي"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

استبدل `USERNAME/REPO_NAME` باسم حسابك والريبو بتاعك.

> 💡 لو أول مرة تستخدم Git من جهازك، هيطلب منك تعمل Login أو تحط بيانات (`git config --global user.name`, `git config --global user.email`) — دي خطوة تظهر مرة واحدة بس.

## النشر (Deployment)

المشروع مربوط بالفعل بـ Firebase Hosting (`firebase.json` + `.firebaserc`).

1. ثبّت Firebase CLI (مرة واحدة بس على جهازك):
```bash
npm install -g firebase-tools
```

2. سجّل دخول:
```bash
firebase login
```

3. من جوه مجلد `galal-academy`:
```bash
firebase deploy --only hosting:galal-academy-da457-baf3c
```

4. هيديك رابط زي:
```text
https://galal-academy-da457-baf3c.web.app
```

> **GitHub Pages بديل؟** ممكن تستخدمه للصفحات الثابتة بس (زي الصفحة الرئيسية)، لكن مينفعش يشتغل مع Firebase Auth/Firestore بنفس الطريقة لو محتاج Rewrites خاصة. الأفضل تفضل مستخدم Firebase Hosting لأنه هو المتكامل مع باقي المشروع.

## حدود المشروع الحالية — بصراحة

النقط دي مش أخطاء، لكن قرارات معمارية واعية اتوضّحت أول ما ظهرت أثناء البناء، وبتفضل هنا كمرجع:

1. **أسئلة الامتحانات الحقيقية لسه فاضية** (`EXAM_DATA_HERE` في `data/courses.js`) — النظام بيتعامل مع الحالة دي بشكل طبيعي، وفيه امتحان تجريبي واحد شغال بالكامل للتجربة.
2. **الغش في الـ XP نظريًا ممكن** لأن تصحيح الامتحان بيحصل في المتصفح مش في سيرفر موثوق. الحل الكامل محتاج **Cloud Function** تصحّح من على السيرفر — موضّح كـ "BACKEND REQUIRED" في `firestore.rules`.
3. **تعديل محتوى الكورسات** (حصص/فيديوهات جديدة) بيتم من `data/courses.js` مباشرة في الكود، مش من واجهة إدمن — قرار معماري عشان نلتزم بمبدأ "Data-Driven من ملف واحد" اللي اتفقنا عليه.
4. **تتبّع الزيارات والمشاهدات** (Analytics الحقيقي) لسه مش موجود. القسم ده في `admin-analytics.html` موسوم بوضوح `DEMO DATA`. الإيرادات بس هي الجزء الحقيقي المحسوب فعليًا.
5. **الدفع لسه يدوي بالكامل** (فودافون كاش + مراجعة إدمن) — مفيش Payment Gateway حقيقي، وده كان مطلوب بالظبط في المواصفات الأصلية.
6. **AI Assistant** مطلوب في المواصفات الأصلية كـ Placeholder فقط (`YOUR_AI_API_KEY`) — لسه معملناش الواجهة بتاعته، ممكن نضيفها كمرحلة إضافية لو حبيت.
7. **الـ Progress bar بتاع تقدم الطالب في كل كورس** (نسبة الحصص المكتملة) لسه ثابت على 0% — النظام الفعلي لتتبّع "شاهدت الفيديو ده" مش موجود لسه، محتاج واجهة مشاهدة دروس مخصصة.

- شات مباشر بين الطالب والإدمن

- واجبات (Assignments) منفصلة عن الامتحانات
- واجهة Galal AI Assistant فعلية (متصلة بـ Anthropic أو OpenAI API)
